# NEXORA — исправленная версия

## Что исправлено
- JavaScript конфигуратора встроен прямо в `index.html`: выбор сценария, бюджетный ползунок и кнопки работают даже если при публикации забыли отдельный `script.js`.
- Кнопки «Заказать подбор», «Подобрать ноутбук» и передача опроса прокручивают страницу к форме без перехода по hash и без перезагрузки.
- Отправка формы перехватывается через `preventDefault()`: страница не должна прыгать наверх при нажатии «Отправить заявку».
- Ошибка подключения теперь отображается прямо под формой; введённые данные не очищаются, кнопка снова становится доступной.
- Основная логика также сохранена в `script.js` для удобства редактирования. При изменении логики синхронизируй его с inline-скриптом в `index.html`.

## Запуск
Открой `index.html` или загрузи всю папку на хостинг. Для конфигуратора и навигации дополнительных сервисов не требуется.

## Важно: Telegram
Форма не может самостоятельно отправить заявку в Telegram без серверного адреса и учётных данных бота. Чтобы включить реальную доставку:
1. Создай Telegram-бота через @BotFather.
2. Создай Cloudflare Worker из `worker/worker.js`.
3. В настройках Worker добавь `TELEGRAM_BOT_TOKEN` как Secret и `TELEGRAM_CHAT_ID` как Variable/Secret.
4. Опубликуй Worker.
5. Вставь его URL в `const workerUrl = '...'` в `script.js` и в аналогичную строку внутри встроенного скрипта `index.html`.
6. Повторно загрузи сайт на хостинг.

Пока URL Worker пустой, форма покажет понятное сообщение, что заявка не отправлена. Это намеренно — сайт не будет делать вид, что заявка доставлена.
