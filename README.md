# NEXORA — Supabase Auth + Cloudflare Pages

## Что добавлено
- Регистрация по email и паролю через Supabase Auth.
- Вход и выход из аккаунта.
- Видео скрыты для гостей и доступны после авторизации.
- Сессия сохраняется через Supabase в браузере.
- Существующая заявка в Telegram и видеоплеер сохранены.

## Настройка Supabase (обязательно)
1. В Supabase открой Authentication → URL Configuration.
2. В Site URL укажи домен опубликованного сайта NEXORA, например `https://nexora-8g7.pages.dev`.
3. В Redirect URLs добавь `https://nexora-8g7.pages.dev/**` и локальный адрес, если тестируешь локально.
4. В Authentication → Providers → Email оставь Email включённым. Подтверждение email можно оставить включённым: после регистрации пользователь должен подтвердить почту.
5. Не публикуй Secret/service_role key и пароль базы данных. В браузере используется только Publishable key.

## Публикация
Загрузи содержимое архива в Cloudflare Pages тем же способом, которым обновлял сайт раньше. Сохрани `_worker.js` — он нужен для существующей отправки заявок в Telegram.

## Важное ограничение доступа к YouTube
Эта версия закрывает раздел видео в интерфейсе для гостей. Поскольку ролики размещены на YouTube и их ID встроены в публичный JavaScript, это не DRM-защита: технически знающий посетитель может получить прямую ссылку на публичный ролик. Если требуется реальная защита контента, видео нужно хранить в приватном видеохранилище с авторизацией и подписанными ссылками.
