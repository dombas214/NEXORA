# NEXORA — сайт подбора компьютеров и ноутбуков

## Что исправлено
- Рабочие обработчики кнопок меню, фильтров, конфигуратора ПК и подбора ноутбука.
- Анкета из 3 вопросов переносит ответы в заявку; после ввода имени и контакта заявка отправляется в Telegram.
- Форма показывает успешный результат или понятную ошибку, не очищая введённые данные при неудачной отправке.
- Cloudflare Worker проверяет данные, отправляет HTML-безопасное сообщение в Telegram и возвращает статус отправки.
- GET-проверка Worker показывает, запущен ли endpoint и заданы ли обе переменные окружения.

## Настройка Cloudflare и Telegram

1. В Cloudflare Dashboard открой Worker, который принимает заявки.
2. Вставь в него содержимое `worker/worker.js` и нажми **Deploy**.
3. В **Settings → Variables and Secrets** должны быть:
   - `TELEGRAM_BOT_TOKEN` — Secret (токен бота от BotFather).
   - `TELEGRAM_CHAT_ID` — Variable или Secret (ID чата, куда слать заявки).
4. Убедись, что бот уже запускали командой `/start` в личном чате. Для группы добавь бота в группу и проверь права.
5. Скопируй публичный URL опубликованного Worker, например `https://nexora-form.<твой-субдомен>.workers.dev`.
6. Открой `script.js` и в первой строке настройки замени `ВСТАВЬ_URL_CLOUDFLARE_WORKER` на свой реальный URL:

   `const workerUrl = "https://твой-worker.ТВОЙ-СУБДОМЕН.workers.dev";`

7. Загрузи обновлённые файлы сайта в Cloudflare Pages.

**Важно:** токен бота и Chat ID не нужно вставлять в `script.js` или HTML. Они остаются только в настройках Worker. В браузер передаётся только публичный URL Worker.

## Проверка

- Открой URL Worker в браузере. Должен вернуться JSON с `"ok":true` и `"configured":true`.
- На сайте заполни анкету или открой форму заявки, введи имя и контакт и отправь её.
- Уведомление должно появиться в указанном Telegram-чате.

Если `configured:false`, проверь имена переменных в Cloudflare и сделай Deploy после их добавления. Если Telegram отвечает ошибкой, проверь правильность Chat ID, токена и то, что пользователь/группа уже начали диалог с ботом.

## Состав
- `index.html` — страница сайта и стили.
- `script.js` — интерактивность и отправка заявок.
- `styles.css` — отдельная копия стилей (страница также содержит встроенные стили).
- `worker/worker.js` — Cloudflare Worker для Telegram.
